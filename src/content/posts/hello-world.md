## Table of contents

## 为什么要有自己的站点

社交平台上的文字，像是寄存在别人仓库里的东西。而这里不同：**内容是我自己的**，格式是我定的，十年后再打开它大概还是这个样子。

> 写作最大的好处，是逼你把模糊的直觉，整理成能被别人读懂、也能被自己反驳的句子。

所以这个站点的定位很简单：

- 技术笔记：踩过的坑、验证过的方案
- 读书与思考：值得反复咀嚼的东西
- 生活片段：当时觉得没什么、后来会想翻回来看的东西

## 日常怎么用

整个站点只有三个动作：

1. **写文章** —— 在 `src/content/posts/` 里新建一个 `.md` 文件，文件名就是网址
2. **改配置** —— 站点名字、作者、社交链接都在 `astro-paper.config.ts` 一个文件里
3. **发布** —— `git push`，托管平台会自动构建上线

本地预览只需要一条命令：

```bash
pnpm dev
```

打开 <http://localhost:4321> 就能看到效果，改动会实时刷新。

## 一篇文章的头部信息

每篇文章开头那段 `---` 包起来的内容叫 frontmatter，它决定了文章的元信息：

```yaml
---
title: 文章标题
author: 0xouzm
pubDatetime: 2026-08-20T09:30:00+08:00
featured: false # 设为 true 会置顶到首页
draft: false # 设为 true 则只在本地可见
tags:
  - 随笔
  - 建站
description: "一句话摘要，会出现在列表页、搜索结果和 RSS 里"
---
```

> [!TIP]
> 站内搜索由 Pagefind 提供，索引在构建时生成——所以搜索的是**正文全文**，不只是标题。
